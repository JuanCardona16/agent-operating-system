# Evaluation Rubrics

## Developer Rubric

| Dimension | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Correctness | incorrect | partial | mostly correct | correct |
| Tests | absent | weak | adequate | comprehensive |
| Scope | uncontrolled | broad | acceptable | minimal |
| Maintainability | poor | weak | good | excellent |
| Safety | unsafe | concerns | acceptable | safe |

## Reviewer Rubric

Evaluar:

```text
bug detection
severity classification
false positives
false negatives
actionability
```

## Architect Rubric

Evaluar:

```text
requirements coverage
trade-offs
simplicity
scalability
failure handling
maintainability
```

## Rule

Una rúbrica debe describir qué significa cada score antes de ejecutar la evaluación.
