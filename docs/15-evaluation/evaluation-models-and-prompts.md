## Model Selection

Evaluar:

```text
quality
latency
cost
tool use
context handling
failure behavior
```

## Prompt Evaluation

Medir:

- adherence;
- correctness;
- hallucination rate;
- tool discipline;
- output structure;
- robustness.

## Rule

No seleccionar modelos únicamente por benchmark general. Evaluar contra tareas reales del sistema.
