# Security Evaluation

## Security Test Categories

```text
prompt injection
secret exposure
permission bypass
unsafe command
malicious repository content
tool output injection
cross-project leakage
memory poisoning
```

## Security Gate

```text
critical vulnerability
        ↓
BLOCK RELEASE
```

## Adversarial Testing

Introducir casos diseñados para provocar:

```text
policy violation
tool abuse
data leakage
instruction hijacking
```

## Rule

Los tests de seguridad deben ejecutarse periódicamente y después de cambios relevantes.
