# Memory Evaluation

## Metrics

```text
retrieval_precision
retrieval_recall
stale_memory_rate
irrelevant_context_rate
memory_usefulness
cross-scope_leakage
```

## A/B

```text
Agent without memory
vs
Agent with memory
```

Comparar:

```text
quality
cost
latency
tool calls
errors
```

## Critical Test

Verificar que:

```text
Project A memory
```

nunca aparezca en:

```text
Project B context
```

## Rule

La memoria debe mejorar resultados netos, no simplemente aumentar el contexto disponible.
