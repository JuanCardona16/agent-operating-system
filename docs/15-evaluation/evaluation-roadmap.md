# Evaluation Roadmap

## Phase 1

```text
deterministic tests
golden dataset
basic metrics
```

## Phase 2

```text
workflow evaluation
regression suite
security tests
```

## Phase 3

```text
LLM judges
human sampling
model comparison
```

## Phase 4

```text
continuous evaluation
release gates
performance dashboards
```

## Phase 5

```text
adaptive benchmark generation
failure clustering
automatic regression discovery
```

## Principle

```text
Build
 ↓
Evaluate
 ↓
Observe
 ↓
Improve
 ↓
Evaluate again
```

La evaluación debe convertirse en un ciclo permanente del sistema, no en una fase que termina después del desarrollo.
