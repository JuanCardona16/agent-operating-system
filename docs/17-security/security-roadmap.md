# Security Roadmap

## Phase 1 — Baseline

```text
permissions
tool controls
workspace isolation
secret handling
```

## Phase 2 — Hardening

```text
sandboxing
network controls
command classification
dependency security
```

## Phase 3 — Adversarial

```text
prompt injection tests
memory poisoning tests
tool abuse tests
security regression
```

## Phase 4 — Production

```text
central policy
audit
incident response
security monitoring
```

## Phase 5 — Advanced

```text
dynamic risk scoring
behavior anomaly detection
automated containment
```

## Principle

La autonomía debe aumentar solamente cuando los controles de seguridad puedan demostrar que soportan esa autonomía.
