# Security Incidents

## Incident Flow

```text
Detect
 ↓
Contain
 ↓
Investigate
 ↓
Remediate
 ↓
Verify
 ↓
Document
```

## Examples

```text
secret exposure
permission bypass
malicious command
cross-project leakage
prompt injection success
supply-chain compromise
```

## Incident Record

```yaml
incident:
  id:
  severity:
  detection:
  affected_scope:
  containment:
  root_cause:
  remediation:
  lessons:
```

## Rule

Los incidentes deben alimentar los datasets de evaluación y regresión.
