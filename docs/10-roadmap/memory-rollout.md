# Memory Rollout

## Phase 1 — No Persistent Memory
Contexto limitado a la ejecución actual.

## Phase 2 — Task Memory
Persistir decisiones, findings, artifacts y errores relevantes.

## Phase 3 — Project Memory
Persistir arquitectura, convenciones, dependencias y decisiones.

## Phase 4 — Agent Memory
Persistir conocimiento específico de roles.

## Phase 5 — Organizational Memory
Compartir conocimiento validado entre proyectos cuando corresponda.

## Introduction Criteria

```text
Repeated context
+
High retrieval value
+
Stable provenance
```

> Primero demostrar qué información vale la pena conservar; después automatizar su persistencia.
