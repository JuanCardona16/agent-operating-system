# Milestones

## M0 — Architecture Ready
**Goal:** diseño preparado para implementación.

**Success Criteria**
```text
Architecture approved
Contracts identified
Risks documented
```

## M1 — Runtime Bootstrap
**Goal:** ejecutar el runtime mínimo.

**Success Criteria**
```text
Runtime starts
Configuration validates
Events are emitted
Errors are visible
```

## M2 — First Agent
**Goal:** ejecutar el primer agente real.

**Agent:** `developer`

**Success Criteria**
```text
Receives task
Reads repository
Modifies code
Returns result
```

## M3 — First Real Task
**Goal:** completar una tarea real.

**Success Criteria**
```text
Code change
Tests
Git diff
Structured result
```

## M4 — Tool System
**Goal:** centralizar herramientas y permisos.

**Success Criteria**
```text
Tool registry
Permission checks
Input validation
Audit
Timeouts
```

## M5 — Multi-Agent Handoff
**Goal:** entregar trabajo entre agentes.

**Flow:** `Analyst → Developer`

**Success Criteria**
```text
Structured handoff
Context preserved
No direct coupling
```

## M6 — Development Team
**Goal:** equipo mínimo.

**Team**
```text
Analyst
Architect
Developer
Tester
Reviewer
```

**Success Criteria:** completar una feature pequeña end-to-end.
