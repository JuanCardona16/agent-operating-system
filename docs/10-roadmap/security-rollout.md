# Security Rollout

## Phase 1 — Basic Controls
```text
Environment Secrets
Workspace Isolation
Basic Permissions
```

## Phase 2 — Tool Security
```text
Permission Checks
Risk Classification
Timeouts
Audit
```

## Phase 3 — Execution Security
```text
Sandboxing
Network Controls
Command Restrictions
```

## Phase 4 — Governance
```text
Approval Gates
Policy Engine
Audit Trail
Rollback
```

## Phase 5 — Advanced Security
```text
Threat Detection
Anomaly Detection
Automated Containment
```

> La capacidad de ejecutar una acción nunca debe implicar automáticamente autorización para ejecutarla.
