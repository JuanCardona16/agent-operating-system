# Workflow Rollout

## Workflow 1 — Direct Implementation

```text
Task → Developer → Test → Result
```

## Workflow 2 — Implementation + Review

```text
Task → Developer → Tester → Reviewer → Result
```

## Workflow 3 — Planned Feature

```text
Task → Analyst → Architect → Developer → Tester → Reviewer
```

## Workflow 4 — Research-Driven

```text
Task → Analyst → Researcher → Architect → Developer → Tester → Reviewer
```

## Workflow 5 — Governed Development

```text
Task
 ↓
Analyst
 ↓
Architect
 ↓
Security
 ↓
Developer
 ↓
Tester
 ↓
Reviewer
 ↓
Quality Gate
 ↓
Approval
 ↓
Done
```

> Cada nuevo workflow debe demostrar valor frente al workflow anterior.
