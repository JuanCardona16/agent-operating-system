# 10 — Roadmap Overview

## Purpose
Este roadmap define la secuencia de construcción del sistema multiagente de desarrollo de software.

## Principles
1. Construir incrementalmente.
2. Validar cada capa antes de añadir complejidad.
3. Priorizar un MVP pequeño pero funcional.
4. Introducir autonomía progresivamente.
5. Mantener contratos explícitos.
6. Aplicar seguridad desde el inicio.
7. Medir antes de optimizar.
8. Evitar agentes innecesarios.
9. Mantener OpenCode y Gentle-AI desacoplados.
10. Cada milestone debe tener criterios objetivos de salida.

## Strategic Roadmap

```text
PHASE 0  Architecture & Documentation
   ↓
PHASE 1  Foundation
   ↓
PHASE 2  Single-Agent MVP
   ↓
PHASE 3  Tooling
   ↓
PHASE 4  Multi-Agent Collaboration
   ↓
PHASE 5  Workflow Orchestration
   ↓
PHASE 6  Memory
   ↓
PHASE 7  Quality & Review
   ↓
PHASE 8  Observability & Operations
   ↓
PHASE 9  Security & Governance
   ↓
PHASE 10 Advanced Autonomy
```

## Definition of Done
El sistema maduro debe poder recibir tareas reales, coordinar agentes, modificar repositorios de forma controlada, ejecutar tests, revisar cambios, conservar conocimiento útil, explicar sus acciones, recuperarse de fallos, aplicar quality gates y requerir aprobación humana para acciones críticas.

> La autonomía es el resultado final del roadmap, no el punto de partida.
