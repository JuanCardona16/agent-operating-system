# Runtime Validation

## Level 1 — Load

Todos los agentes cargan correctamente.

## Level 2 — Permissions

Cada agente puede utilizar únicamente sus capacidades autorizadas.

## Level 3 — Tool

Las herramientas funcionan dentro del workspace.

## Level 4 — Task

Developer completa una tarea simple.

## Level 5 — Workflow

Developer → Tester → Reviewer funciona.

## Level 6 — Failure

Un test fallido provoca una respuesta correcta del workflow.

## Level 7 — Security

Una operación prohibida es bloqueada.

## Exit

```text
all critical validations pass
```
