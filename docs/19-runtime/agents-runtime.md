# Runtime Agents

## MVP Team

### Developer

Responsable de implementar cambios.

```text
read → plan → modify → test → report
```

### Tester

Responsable de validar comportamiento.

```text
inspect → execute tests → add/fix tests when authorized → report
```

### Reviewer

Responsable de revisar cambios.

```text
inspect diff → identify defects → classify risk → report
```

## Agent Separation

```text
Developer ≠ Tester ≠ Reviewer
```

Esta separación permite detectar errores mediante perspectivas independientes.

## Expansion

Después del MVP:

```text
Analyst
Architect
Researcher
Security
```
