# Runtime Bootstrap

## Objective

Crear el primer runtime reproducible.

## Steps

```text
1. Repository
2. AGENTS.md
3. .opencode/
4. Agent definitions
5. Permissions
6. Model configuration
7. First workflow
8. Validation
```

## Bootstrap Checklist

```text
[ ] OpenCode installed
[ ] repository initialized
[ ] runtime configuration created
[ ] developer created
[ ] tester created
[ ] reviewer created
[ ] first task executed
[ ] tests executed
[ ] review executed
```

## First Task

Debe ser:

- pequeña;
- reversible;
- bien delimitada;
- fácil de verificar.

Ejemplo:

```text
Add a missing unit test for an existing function.
```
