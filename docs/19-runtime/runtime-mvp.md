# Runtime MVP

## Deliverable

Un entorno OpenCode capaz de ejecutar:

```text
developer
tester
reviewer
```

sobre un repositorio real.

## Required

```text
agent definitions
model mapping
permissions
tools
workflow
observability
evaluation
```

## MVP Exit Criteria

- los tres agentes funcionan;
- Developer puede modificar código;
- Tester puede verificarlo;
- Reviewer puede encontrar defectos;
- workflow maneja éxito y fallo;
- permisos peligrosos están bloqueados;
- ejecución es trazable;
- resultados tienen evidencia.
