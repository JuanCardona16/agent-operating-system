# Memory Governance

## Governance Questions

Antes de persistir una memoria:

1. ¿Es útil?
2. ¿Es correcta?
3. ¿Cuál es su fuente?
4. ¿Qué scope necesita?
5. ¿Cuánto tiempo debe vivir?
6. ¿Quién puede leerla?
7. ¿Puede contaminar decisiones futuras?

## Memory Review

Periódicamente revisar:

```text
duplicates
stale records
contradictions
low-confidence records
unused memories
sensitive content
```

## Promotion

```text
Execution Finding
      ↓
Validated
      ↓
Project Memory
      ↓
Repeatedly confirmed
      ↓
Knowledge
```

No promover automáticamente todos los outputs de agentes.

## Rule

La memoria debe evolucionar mediante un proceso de validación, no mediante acumulación indiscriminada.
