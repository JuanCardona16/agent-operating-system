# Project Memory

## Purpose

Conservar conocimiento estable y útil sobre el repositorio.

## Typical Contents

```text
architecture decisions
coding conventions
important dependencies
repository structure
known constraints
deployment conventions
testing strategy
known technical debt
```

## Examples

```text
The API uses PostgreSQL.
Authentication is handled by module X.
Tests must run with command Y.
Public API compatibility is required.
```

## Sources

Preferir:

```text
repository
documentation
verified tool output
human decision
```

## Trust

Project memory no debe convertirse automáticamente en autoridad superior a:

```text
system policy
security policy
current repository state
explicit task instructions
```

## Staleness

Las decisiones técnicas deben poder marcarse como:

```text
active
deprecated
superseded
unknown
```
