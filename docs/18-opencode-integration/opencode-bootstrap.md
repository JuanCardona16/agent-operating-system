# OpenCode Bootstrap

## Goal

Crear una primera implementación mínima antes de completar toda la plataforma.

## Bootstrap Checklist

```text
[ ] initialize repository
[ ] create AGENTS.md
[ ] create .opencode/ structure
[ ] create developer agent
[ ] create tester agent
[ ] create reviewer agent
[ ] configure model mapping
[ ] configure permissions
[ ] define first workflow
[ ] run first coding task
[ ] capture trace
[ ] evaluate result
```

## First Task

Elegir una tarea pequeña y reversible:

```text
add a small feature
fix a contained bug
add tests to an existing module
```

Evitar comenzar con una migración grande.

## Success

El primer experimento debe demostrar:

```text
agent → tool → code → test → review
```

de extremo a extremo.
