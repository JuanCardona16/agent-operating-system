# OpenCode Integration Checklist

## Architecture

- [ ] Agent roles mapped.
- [ ] Workflows defined.
- [ ] Tool matrix defined.
- [ ] Permission matrix defined.
- [ ] Memory boundaries defined.
- [ ] Evaluation criteria defined.
- [ ] Observability requirements defined.
- [ ] Security boundaries defined.

## Runtime

- [ ] OpenCode project initialized.
- [ ] Agent templates converted to runtime definitions.
- [ ] Models configured.
- [ ] Permissions configured.
- [ ] Commands/workflows configured.

## Validation

- [ ] Developer task passes.
- [ ] Tests execute.
- [ ] Reviewer detects intentional issue.
- [ ] Security blocks prohibited operation.
- [ ] Trace is complete.
- [ ] Evaluation produces score.

## Production Readiness

- [ ] No critical security failures.
- [ ] Regression suite exists.
- [ ] Cost limits exist.
- [ ] Observability works.
- [ ] Recovery strategy exists.
- [ ] Human approval exists for high-risk operations.
