# OpenCode Integration MVP

## Objective

Crear el primer equipo funcional de agentes de codificación dentro de OpenCode.

## MVP

```text
OpenCode project
+
AGENTS.md
+
developer
+
tester
+
reviewer
+
basic permissions
+
basic workflow
+
basic observability
+
basic evaluation
```

## First Workflow

```text
User Task
 ↓
Developer
 ↓
Tester
 ↓
Reviewer
 ↓
Result
```

## MVP Exit Criteria

- los agentes se pueden invocar;
- cada agente tiene scope definido;
- permisos funcionan;
- developer puede modificar código;
- tester puede ejecutar pruebas;
- reviewer puede inspeccionar cambios;
- el workflow produce evidencia;
- fallos son observables;
- no existen permisos peligrosos por defecto.
