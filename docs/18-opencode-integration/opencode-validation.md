# OpenCode Validation

## Validation Levels

### Level 1

Agent loads successfully.

### Level 2

Agent can use permitted tools.

### Level 3

Agent respects permissions.

### Level 4

Agent completes isolated task.

### Level 5

Multiple agents cooperate.

### Level 6

Memory, evaluation and observability work together.
